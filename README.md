# Práctica 08 - Patrón Factory en C++

Repositorio con los ejercicios resueltos y propuestos de la Práctica 08 de Tecnología de Objetos (UNSA, semestre 2026-B).

- **Autora:** Nagin Jazmin Carfer Carpio
- **Docente:** Mg. Ing. Rene Alonso Nieto Valencia

## Carpetas

- `ejercicio_a_juguetes`: Fábrica de juguetes en C++.
- `ejercicio_b_abstract_factory`: Ejemplo estándar de Abstract Factory.
- `propuesto_1_recetas`: Recetas de cocina del Perú y del mundo con el patrón Factory.
- `propuesto_2_interfaz_grafica`: Interfaz gráfica con botones y casillas para Windows, Mac y Linux.
