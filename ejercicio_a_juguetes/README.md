# Ejercicio A - Fábrica de Juguetes

Implementación del patrón Factory en C++ para fabricar juguetes (`Car`, `Bike` y `Plane`). Se inicializan los atributos `name` y `price` en los constructores y se incluye un destructor virtual en la clase base `Toy`.

## Compilación y ejecución

```bash
g++ -Wall -Wextra -std=c++17 main.cpp -o juguetes
./juguetes
```
