# Ejercicio B - Patrón Abstract Factory

Implementación estándar del patrón Abstract Factory en C++ con dos familias de productos (`ProductoA` y `ProductoB`) y dos fábricas concretas (`CFactory1` y `CFactory2`).

## Compilación y ejecución

```bash
g++ -Wall -Wextra -std=c++17 main.cpp -o abstract_factory
./abstract_factory
```
