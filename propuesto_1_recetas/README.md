# Propuesto 1 - Recetas de Cocina

Implementación del patrón Factory aplicado a recetas de cocina de distintas regiones del Perú y del mundo (`Ceviche`, `RocotoRelleno`, `PizzaNapolitana` y `Ramen`), cada una con origen, tiempo, ingredientes y pasos propios.

## Compilación y ejecución

```bash
g++ -Wall -Wextra -std=c++17 main.cpp -o recetas
./recetas
```
